# Петрострой монтаж - Сайт визитка

Профессиональный сайт для компании "Петрострой монтаж" - строительное унитарное предприятие, специализирующееся на строительстве, ремонте и монтажных работах.

## 📋 Описание

Сайт визитка компании включает:

- **Главная страница** с информацией о компании
- **Секция услуг** с описанием всех предоставляемых услуг
- **О компании** с статистикой и опытом
- **Контактная форма** для заявок
- **Полная SEO оптимизация**
- **Мобильная адаптивность**
- **Schema.org структурированные данные**
